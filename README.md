# Zapret для LG webOS

Неофициальная адаптация **Flowseal Zapret для телевизоров LG с root и Homebrew Channel**.
Приложение управляет обходом DPI прямо на телевизоре: запуск, остановка,
выбор одной из 22 стратегий и автозапуск. Роутер и постоянно работающий компьютер
для повседневного использования не требуются.

Основа стратегий и ресурсов — **[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) 1.10.4**.
Спасибо **Flowseal** и автору оригинального **[zapret — bol-van](https://github.com/bol-van/zapret)**.
Подробнее об авторах и лицензиях: [NOTICE.md](NOTICE.md). Это самостоятельная
неофициальная адаптация, а не официальный релиз Flowseal, bol-van или LG.

## Подойдёт ли моему телевизору?

**IPK не универсален для всех LG.** Он рассчитан на телевизоры с webOS,
правами root и работающей root-службой Homebrew Channel. Одного Developer Mode
недостаточно. Для NetCast и телевизоров без доступного root эта версия не подходит.

Проверенная основа: **32-битный ARM (`armv7l`), webOS SDK 4.10.0, Python 2.7.12,
Linux 4.4.84**. Воспроизведение YouTube подтверждено владельцем на двух моделях:

| Модель | Прошивка | Результат |
| --- | --- | --- |
| LG 60UM7100PLB | 05.40.97 | YouTube работает; установленная версия 0.2.0 |
| LG 32LM6350PLA | 05.40.97 | YouTube работает; установленная версия 0.2.1 |

Остальные модели и новые поколения webOS пока не проверены. Суффикс `_all.ipk`
обозначает архитектурную метку пакета, а не поддержку каждого телевизора.
Требования к ядру, Python и библиотекам перечислены в
[таблице совместимости](docs/compatibility.md).

**На совместимом телевизоре менять код обычно не нужно:** установите готовый IPK
и подберите стратегию через пульт. Результат зависит от провайдера и маршрута
до видеосервера. Даже одна домашняя сеть не гарантирует одинаковые возможности
ядра и прошивки у разных моделей. Агент для обычной установки не нужен.

## Установка и первый запуск

1. Проверьте root и Homebrew Channel по [инструкции установки](docs/installation.md).
2. Скачайте `org.flowseal.webos_0.2.1_all.ipk` и соответствующий `.sha256`
   из [Releases](https://github.com/martylex/zapret-webos/releases).
3. Установите IPK на rooted-телевизор через webOS Dev Manager.
4. Откройте **Flowseal Zapret** на телевизоре. Нажмите **7**, затем **0**, затем **5**,
   чтобы выбрать **SIMPLE FAKE**. Это первая стратегия, которую стоит проверить:
   она работала на двух проверенных телевизорах. Настройка приложения
   для новой конфигурации остаётся **FAKE TLS AUTO ALT3**.
5. Нажмите **Start / Запуск** или клавишу **3**, дождитесь **Running**, закройте
   приложение кнопкой Back и проверьте воспроизведение в YouTube.
6. Если всё работает, включите **Autostart** в приложении по желанию.

Закрытие интерфейса оставляет службу работающей. Чтобы отключить обход, откройте
приложение и нажмите **Stop**. Интерфейс текущей версии на английском;
инструкция и описание проекта — на русском.

Если готовый релиз ещё не опубликован, IPK можно собрать по
[инструкции для разработчиков](docs/development.md) без webOS SDK.

## Управление пультом

Поддерживаются указатель Magic Remote, стрелки и OK. Короткие нажатия цифр
работают, пока приложение открыто.

| Кнопка | Действие |
| --- | --- |
| 1 | FAKE TLS AUTO ALT3 |
| 2 | FAKE TLS AUTO ALT2 |
| 3 | Запуск |
| 4 | Остановка |
| 5 | Перезапуск |
| 6 | Показать или скрыть диагностику |
| 7 | Открыть список всех 22 стратегий |
| 0 | Обновить состояние |
| Back | Закрыть список стратегий, затем интерфейс |

В списке стратегий можно выбрать вариант указателем, стрелками/OK либо
двузначным кодом **01–22**. Смена стратегии перезапускает работающую службу.
Если служба остановлена, меняется только сохранённый выбор.
Коды и результаты прежних проверок: [стратегии](docs/strategy-results.md).

## Возможности и ограничения

- 22 адаптированные стратегии из Flowseal 1.10.4, исходные списки и сетевые заготовки.
- Обработка исходящего IPv4-трафика приложений телевизора через TUN и raw sockets.
- Работа без NFQUEUE; автоматический обратный путь для ядер со строгим `rp_filter`.
- Поддержка дополнительных доменов из `config/user-domains.txt` при сборке.
- Выбранная стратегия и настройка автозапуска сохраняются между запусками интерфейса.

Обрабатывается **только IPv4**. QUIC v1 поддержан в пределах реализованного разбора
Initial; другие версии, скрытый SNI и весь набор функций Windows `winws.exe`
не покрываются полностью. Игровой фильтр выключен. Совместная работа с VPN
и бесшовное переключение Wi-Fi/Ethernet не поддержаны. Движок принимает
исходящий интерфейс `wlan0` или `eth0`.

Приложение создаёт временный TUN и маршруты, не меняя системные DNS, firewall,
sysctl и исходный default route. После остановки временные маршруты удаляются.
Автозапуск включается пользователем отдельно.

Это не VPN: приложение не создаёт зашифрованный туннель и не скрывает IP-адрес.
Оно не снимает ограничения, которые сам сервис применяет к аккаунту или региону.

## Что проверено

На двух телевизорах проверены работа службы и интерфейса, стратегии и соединения
с реальными видеосерверами; владелец подтвердил воспроизведение YouTube.
Пакетные проверки охватывают контрольные суммы и сохранность передаваемых данных
для всех 22 стратегий. На втором ТВ проверен обратный путь при строгом `rp_filter`.

Перезагрузка с включённым автозапуском, фактическое выполнение хука при удалении,
длительная пропускная способность и другие модели пока не проверены.
Тестовый запрос скачивания вернул HTTP 403 и не подтвердил скорость загрузки;
успешный HTTP 204 подтверждает соединение, но сам по себе не доказывает проигрывание видео.

Публичный IPK версии 0.2.1 пересобран с лицензией адаптации и описанием происхождения
ресурсов. Код сетевого движка совпадает с рабочей локальной версией 0.2.1;
повторная установка публичной сборки на телевизоры не выполнялась.
