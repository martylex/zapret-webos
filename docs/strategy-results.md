# Стратегии и результаты прежних проверок

Ниже — результаты сравнительных HTTPS-проверок на первом тестовом ТВ в одной сети.
Они отражают прежний запуск, а не универсальную пригодность стратегии. Запросы
выполнялись с проверкой TLS-сертификатов по IPv4 к двум реальным видеосерверам,
YouTube и Discord. Проверялось восстановление маршрутов после каждой стратегии.

`OK` означает завершение TLS/HTTP. `28` — тайм-аут, `35` — ошибка TLS.
Успешное соединение не доказывает проигрывание видео или устойчивую скорость.
IP-адреса, полные имена видеосерверов и личные журналы не публикуются.

На втором ТВ последующее сравнение SIMPLE FAKE, ALT9, ALT12, ALT13 и EXP
также завершило все проверки четырёх видеосерверов, включая короткий ClientHello.
По окончании выбрана SIMPLE FAKE, автозапуск оставлен включённым.
Запрос для проверки длительной загрузки вернул HTTP 403 у всех пяти стратегий,
поэтому скорость этим опытом не подтверждена. Воспроизведение YouTube
на обоих ТВ отдельно подтвердил владелец.
