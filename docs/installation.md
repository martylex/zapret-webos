# Установка и использование

## Подготовка телевизора

Нужен телевизор LG с **webOS, root и Homebrew Channel с правами root**.
Проверьте [совместимость](compatibility.md), [базу моделей и прошивок](https://cani.rootmy.tv/)
и [инструкцию webOSbrew](https://www.webosbrew.org/rooting/).
IPK приложения не устанавливает root и не содержит программы получения root.

Обычный Developer Mode позволяет устанавливать приложения, но не даёт движку
необходимых системных прав. Подготовка root зависит от модели.
Не включайте Developer Mode поверх уже настроенного root без проверки инструкции
для своего способа установки. Отключите другие VPN на телевизоре.

## Установка готового IPK

1. Откройте [Releases](https://github.com/martylex/zapret-webos/releases).
2. Скачайте `org.flowseal.webos_0.2.1_all.ipk` и одноимённый файл `.sha256`.
3. Проверьте SHA256. В PowerShell, из папки загрузки:

```powershell
$ipk = 'org.flowseal.webos_0.2.1_all.ipk'
$expected = ((Get-Content -LiteralPath "$ipk.sha256").Trim() -split '\s+')[0]
$actual = (Get-FileHash -LiteralPath $ipk -Algorithm SHA256).Hash
if ($actual -ine $expected) { throw 'SHA256 не совпадает. Скачайте пакет заново.' }
```

4. Установите [webOS Dev Manager](https://github.com/webosbrew/dev-manager-desktop/releases)
   на компьютер и добавьте **rooted**-телевизор по его адресу и вашим SSH-настройкам.
   Не используйте профиль обычного Developer Mode вместо root-подключения.
5. В разделе приложений выберите установку локального IPK и укажите скачанный файл.
   Телевизор должен иметь уже работающую root-службу Homebrew Channel.
6. Откройте **Flowseal Zapret** в списке приложений телевизора.

Готовый релиз не требует Python или Node.js на компьютере. Они нужны только
для сборки и описанного ниже альтернативного установщика из исходников.

## Первый запуск

1. Дождитесь **Stopped** или **Running** без ошибки root-службы.
2. Нажмите **7**, затем **0**, затем **5** — выберите **SIMPLE FAKE**.
3. Если служба остановлена, нажмите **Start** или **3**.
4. После появления **Running** нажмите **Back**, откройте YouTube и запустите видео.
5. Если выбранная стратегия работает, при желании включите **Autostart**.

Закрытие интерфейса не останавливает службу. **Stop** или **4** останавливает её
и удаляет временные маршруты. Автозапуск при новой установке выключен.
Полный цикл выключения/включения с автозапуском пока не проверен.

## Если видео не воспроизводится

- Проверьте, что статус **Running**, а не только то, что открывается интерфейс.
- Закройте и заново откройте YouTube после смены стратегии.
- Через **7** попробуйте **17 / ALT9**, **21 / ALT13**, **22 / EXP**;
  **20 / ALT12** также проходила проверки видеосерверов, но не всех остальных целей.
- Убедитесь, что другой VPN или прокси не перехватывает трафик телевизора.
- Учтите, что IPv6 не обрабатывается этим движком.
- Откройте диагностику клавишей **6** и сохраните текст ошибки без личных данных.

Стратегии зависят от провайдера и сервера и могут переставать работать со временем.
Смена стратегии не требует правки кода. Ошибка root-службы, отсутствие Python/TUN
или неподдержанный интерфейс относятся к [совместимости](compatibility.md).

## Альтернативная установка из исходников через PowerShell

Нужны Windows, Python 3, PowerShell и `ssh.exe`.
Сначала [соберите пакет](development.md), затем:

```powershell
python tools/build_install_script.py
$tvAddress = Read-Host 'IPv4-адрес вашего ТВ'
$credential = Get-Credential -UserName root -Message 'SSH-пароль телевизора'
$env:FLOWSEAL_SSH_PASSWORD = $credential.GetNetworkCredential().Password
try {
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/Invoke-TV.ps1 -TVAddress $tvAddress -Script diagnostics/install-tv.sh -AcceptNewHostKey -Log diagnostics/install-result.txt
    if ($LASTEXITCODE -ne 0) { throw 'Установка завершилась с ошибкой. Проверьте журнал.' }
} finally {
    Remove-Item Env:FLOWSEAL_SSH_PASSWORD -ErrorAction SilentlyContinue
}
```

`-AcceptNewHostKey` нужен для первого соединения: он запоминает новый ключ
и отвергает изменение известного. В последующих вызовах параметр можно убрать.
Адрес требуется явно; общего пароля в проекте нет. Пароль вводится через системное
окно и используется только в текущем процессе. Ключи хостов и журналы сохраняются
в игнорируемой папке `diagnostics/`.

Установщик проверяет SHA256 и файлы установленного приложения, затем открывает
интерфейс. При новой установке он не включает обход или автозапуск.
Если служба уже запущена, сначала остановите её в приложении.

## Обновление и удаление

Для обновления нажмите **Stop**, затем установите новый IPK. Выбор стратегии
хранится в `/var/lib/flowseal-webos/config.json`. Встроенный SSH-установщик
сохраняет автозапуск при обновлении; поведение стороннего установщика при вызове
хука удаления может отличаться. Проверьте Autostart после обновления.

Перед удалением отключите **Autostart**, нажмите **Stop**, затем удалите приложение.
Пакет содержит `prerm` для остановки и отключения автозапуска; фактический вызов
этого хука на удалении ещё не проверялся.

Если интерфейс недоступен, для стандартного каталога выполните через root SSH:

```sh
/usr/bin/python -B /media/developer/apps/usr/palm/applications/org.flowseal.webos/native/control.py stop
/usr/bin/python -B /media/developer/apps/usr/palm/applications/org.flowseal.webos/native/control.py autostart-off
ip route show
```

При другом каталоге замените `/media/developer/apps` на фактическую основу установки.
После Stop интерфейс `fszdev` и связанные с ним `/1`-маршруты должны исчезнуть.
