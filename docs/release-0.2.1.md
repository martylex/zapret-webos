# Zapret для LG webOS 0.2.1

Первая публичная сборка неофициальной адаптации Flowseal для rooted-телевизоров LG.
Основа стратегий, списков и сетевых заготовок —
[Flowseal/zapret-discord-youtube 1.10.4](https://github.com/Flowseal/zapret-discord-youtube).
Спасибо Flowseal и [bol-van, автору zapret](https://github.com/bol-van/zapret).

- 22 стратегии, выбор пультом или указателем, запуск/остановка и автозапуск.
- Python-движок TUN/raw sockets вместо Windows-программы.
- Обратный путь для ядер со строгим `rp_filter`.
- Инструкция на русском; интерфейс приложения на английском.
- Сохранены исходные лицензии; добавлены лицензия адаптации и происхождение ресурсов.

**Нужны root, Homebrew Channel и совместимое Linux/Python-окружение.**
Одного Developer Mode недостаточно. Проверены ARM32-телевизоры
LG 60UM7100PLB и 32LM6350PLA, прошивка 05.40.97, SDK 4.10.0.
На первом установлена версия 0.2.0, на втором — 0.2.1;
владелец подтвердил воспроизведение YouTube на обоих.

Публичный IPK пересобран с лицензиями и обновлённым описанием происхождения;
сетевой код не изменён относительно рабочей версии 0.2.1.
Повторная установка этой публичной сборки на ТВ не выполнялась.

Для первой проверки выберите **SIMPLE FAKE**: **7 → 0 → 5**, затем **3 / Start**.
Если стратегия не подходит, выберите другую в интерфейсе; пересборка не требуется.

Ограничения: IPv4, wlan0/eth0, неполное покрытие QUIC,
нет гарантии для других моделей и провайдеров. Длительная скорость загрузки,
цикл загрузки с автозапуском и выполнение хука удаления пока не проверены.

Скачайте IPK и `.sha256`, сверьте хеш и следуйте
[инструкции](https://github.com/martylex/zapret-webos/blob/main/docs/installation.md).
