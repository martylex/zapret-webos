# Сборка и устройство проекта

## Требования на компьютере

- Python **3.8 или новее**, только стандартная библиотека;
- Node.js **18 или новее** для локальной проверки интерфейса;
- Git для работы с исходниками.

webOS SDK, компилятор ARM и Windows-движок для сборки не нужны.
Python 3 на компьютере и системный Python 2.7 на проверенных телевизорах —
разные части процесса.

## Сборка из чистого клона

```powershell
git clone https://github.com/martylex/zapret-webos.git
Set-Location zapret-webos
python tools/build_strategies.py
node tools/test_ui.js
python tools/test_strategies.py
python tools/test_receive.py
python tools/build_ipk.py
python tools/verify_ipk.py
```

Пакет появится в `dist/` вместе с `.sha256` и `package-contents.json`.
Сборка использует только опубликованные исходники; доступ к телевизорам,
SSH-пароли и личные диагностические файлы не нужны. Gzip/TAR-метки времени
фиксированы для повторяемой сборки при одинаковом окружении и исходных байтах.

`python tools/build_install_script.py` создаёт локальный `diagnostics/install-tv.sh`
для [SSH-установки](installation.md). Это файл с пакетом внутри, не установщик root.

## Каталоги

| Каталог | Назначение |
| --- | --- |
| `app/` | Веб-интерфейс и метаданные IPK |
| `native/` | Python-движок IPv4, стратегии, обратный путь и управление службой |
| `source/flowseal-1.10.4/` | Неизменённые используемые материалы Flowseal и исходная лицензия |
| `config/user-domains.txt` | Дополнительные домены для TCP и QUIC при сборке |
| `tools/` | Сборка, проверка пакета и локальные проверки |
| `docs/` | Публичная документация |
| `dist/` | Результаты сборки; не входят в Git |
| `diagnostics/`, `local/` | Личные журналы и записи; не входят в Git |

`.gitignore` использует разрешающий список. Новые исходные файлы добавляйте в него,
чтобы они появились в коммите. Не применяйте `git add -f` к журналам и настройкам.

## Работа движка

Интерфейс вызывает root API Homebrew Channel. Контроллер разрешает фиксированный
набор действий, проверяет личность процесса перед остановкой и хранит настройки
в `/var/lib/flowseal-webos`. Состояние и журнал — в `/tmp/flowseal-webos`.

Движок создаёт непостоянный TUN `fszdev`, направляет в него исходящий IPv4 через
два временных `/1`-маршрута и отправляет пакеты через raw socket физического
интерфейса. Более специфичные LAN-маршруты сохраняются. На ядре со строгим
reverse-path filtering локальные ответы возвращаются через TUN с помощью AF_PACKET.
Системные firewall, DNS, sysctl и исходный default route не переписываются.

При закрытии последнего TUN-дескриптора ядро удаляет интерфейс и маршруты.
Контроллер использует heartbeat и watchdog для зависшего движка.
Автозапуск создаёт ссылку `/var/lib/webosbrew/init.d/70-flowseal-webos`
на `native/startup.sh`.

BAT-файлы Flowseal не исполняются. Сборщик преобразует упорядоченные профили
в `native/strategy_catalog.json` и перечень `app/strategies.js`.
Полная идентичность Windows `winws.exe` не заявляется.

## Проверки

`test_ui.js` работает в Node.js с имитацией DOM, без браузера и подключения к ТВ.
`test_strategies.py` проверяет контрольные суммы, сегментацию, сохранение байтов
TCP-потока, HTTP и путь без timestamps для 22 стратегий. `test_receive.py`
проверяет отбор обратных пакетов: назначение, направление, LAN-маршруты и длину IPv4.

`verify_ipk.py` сверяет структуру пакета, runtime/UI-файлы, неизменность материалов
Flowseal, каталог стратегий, лицензию, SHA256, происхождение ресурсов и манифест.
Эти проверки не заменяют установку на ТВ и воспроизведение видео.

Для новой модели сначала выполните команды из [совместимости](compatibility.md).
Сетевые эксперименты могут останавливать службу и менять стратегию;
проводите их в согласованное с владельцем время.
